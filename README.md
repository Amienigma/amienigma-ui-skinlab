# SkinLab

Interactive phone UI skin lab from [Amienigma Studios](https://amienigma.art.blog/) / The Original Enigma Studios.

**Live:** [amienigma-ui-skinlab.vercel.app](https://amienigma-ui-skinlab.vercel.app)

Preview HarmonyOS, One UI, and iOS screen skins in a studio frame — light and dark wallpapers, device chrome, and a dark-romanticism / cybercore studio shell.

## Stack

React 19 · TanStack Start · Tailwind · Vite · Vercel

## Run locally

```bash
npm install
npm run dev
```

Dev server defaults to `http://localhost:8080`.
